## NeuroTest: a benchtop testbed for evaluating sensing-capable electrophysiology and neurostimulation systems

The information in this repository can be used to assemble and operate the NeuroTest Board (NTB). The design files do not include an electrolyte medium, such as the gel electrophoresis tank suggested for use with the NTB. Example data files are provided for using the neural playback function but end users can also create their own files (see instructions in the User Guide document).

The design files folder contains the gerber file, a bill of materials (bom), and the component placement list (cpl). Designs for housing the NTB (e.g., via a 3d printed shell) and information on a container for the electrolyte medium are not currently included in the design files. We also do not include designs or suggestions for external components, such as a pulse generator, which may be necessary for some end user testing.

Instructions for operating the NTB, including function definitions and command line usage, can be found in the User Guide document. This document or other methods of providing instructions will be updated as new functions are created.

Data files contain a mix of human, rodent, and arbitary waveform data. The .csv files can be used with the signal generator of the NTB to play data into a connected system (e.g., saline tank).
